## About

My Goal Wallet is a straightforward Flutter application that illustrates how weekly savings are calculated. The user enters four inputs, and the app computes and displays the number of weeks and days needed to reach the desired amount.

---

## Inputs

Three text fields and one drop-down button:

| Input | Type | Rule |
|---|---|---|
| Target Amount | TextField | Must be greater than 0 |
| Planning Saving | TextField | Must be greater than 0 |
| Starting Balance | TextField | Must be 0 or more |
| Goal Type | DropdownButton | Selected from list |

---

## Process

When the user taps **Calculate**, the app runs error handling followed by the calculation:

1. Validate all input fields against the rules above
2. Calculate the remaining amount → `remaining = target - startBalance`
3. If `remaining <= 0`, show a dialog saying the target is already reached
4. Otherwise calculate the required time:
   - Weeks needed → `remaining / savePerWeek`
   - Split into exact weeks and leftover
   - Convert the leftover into days

---

## Output

Results are shown in an `AlertDialog` popup. There are two possible outcomes:

- **Target not yet reached** — message showing how many week(s) and day(s) are needed
- **Target already reached** — message confirming the goal is met

---

## Validation Approach

1. Convert input from each TextField using `double.tryParse()`
2. Validate each value against its rule

**If any input is invalid:**
- The matching error flag (`targetError`, `savingError`, `balanceError`) is set to `true`
- The calculation stops
- The TextField shows a red border as an error indicator

**If all inputs are valid:**
- The calculation completes and the result dialog is displayed
